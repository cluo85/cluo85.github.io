北京星环漫宇科技有限公司（以下简称「我们」）是手机游戏《星际商途》（Galaxy Tycoon）的运营者。我们深知个人信息对你的重要性，会按照适用的个人信息保护法律法规处理你的个人信息。请你在使用本游戏前仔细阅读本政策。

一、我们如何收集和使用你的个人信息

（一）提供游戏服务

你的游戏进度、设置项、道具与货币数量保存在设备本地，不会上传到我们的服务器。本游戏不设账号，没有注册、登录、昵称、头像、好友、聊天等功能。

（二）展示广告

本游戏通过第三方广告 SDK 展示广告。广告 SDK 会自行采集设备信息与广告标识符，用于广告投放、效果统计与反作弊。在 iOS 上，只有你在系统跟踪授权弹窗中允许跟踪、并同意个性化广告后，才会使用广告标识符（IDFA）；你可以随时在系统设置中关闭跟踪。个性化广告需要你单独同意，你也可以在「设置 - 隐私与数据」中关闭。

（三）数据分析

在你同意后，我们通过第三方统计 SDK 记录启动、关卡进度、广告观看、内购等事件，用于了解功能使用情况、排查故障。我们不会将统计数据与你的身份关联。

（四）内购与排行榜

在 App Store 版本中，购买由 Apple 处理，我们不会获取你的支付账号、银行卡号或密码。排行榜使用 Apple Game Center，展示的是你在 Game Center 中的昵称与分数。

（五）我们不会主动收集的信息

本游戏不主动收集你的姓名、手机号码、电子邮箱、身份证件号码、通讯录、短信内容、通话记录、照片与视频、麦克风与摄像头内容、精确位置信息或剪切板内容。你主动通过电子邮件联系我们时，我们会处理你的邮箱地址与邮件内容，仅用于答复你的请求。

三、第三方 SDK 清单

为保障相关功能的实现，我们接入了下列第三方 SDK，并对其权限调用进行必要管理。各第三方的具体个人信息处理规则以其隐私政策为准。

1. Google AdMob

SDK 名称：Google Mobile Ads SDK

合作方主体：Google LLC

使用目的：展示广告、广告效果统计

使用场景：展示插屏广告与激励视频广告时

收集的个人信息类型：设备型号、操作系统版本、广告标识符（IDFA 或安卓广告 ID）、IP 地址、大致地区、应用内交互事件

采集方式：SDK 自行采集

隐私政策链接：https://policies.google.com/privacy

2. Firebase Analytics

SDK 名称：Firebase Analytics

合作方主体：Google LLC

使用目的：统计分析、故障排查

使用场景：你同意隐私政策并开启数据分析后

收集的个人信息类型：设备型号、操作系统版本、应用实例标识、应用内事件、由 IP 推断的国家或地区

采集方式：SDK 自行采集

隐私政策链接：https://firebase.google.com/support/privacy

3. Apple StoreKit 与 Game Center

合作方主体：Apple Inc.

使用目的：应用内购买、排行榜

使用场景：你主动购买时；查看或提交排行榜分数时

收集的个人信息类型：购买凭据与交易标识、Game Center 昵称与分数

采集方式：由系统组件采集

隐私政策链接：https://www.apple.com/legal/privacy/

上述 SDK 可能使用随机生成或系统提供的设备相关标识区分设备，具体类型以其隐私政策为准。我们不主动将这些标识与你的现实身份关联。设备相关标识不直接显示你的姓名，但仍可能属于个人信息。

四、我们如何共享、转让、公开披露你的个人信息

1. 共享：上述 SDK 在提供相应功能时按第三节清单处理信息。除实现这些功能所必需的调用外，我们不主动向其他第三方提供你的个人信息。

2. 转让：我们不会主动将你的个人信息转让给任何公司、组织或个人。如因合并、分立、收购等原因依法需要转让，我们会告知你接收方的名称与联系方式，并要求其继续履行个人信息保护义务。

3. 公开披露：我们不会公开披露你的个人信息；依法取得单独同意或法律法规另有规定的除外。排行榜仅在你主动提交分数后展示你的 Game Center 昵称与分数。

五、个人信息出境

上述第三方 SDK（Google、Apple）的服务器可能位于你所在国家或地区境外，可能涉及个人信息出境。我们会依法告知境外接收方、处理目的与方式、信息种类及权利行使方式，并履行单独同意及其他适用的出境合规义务。

六、我们如何存储你的个人信息

1. 存储地域：本地存档保存在你的设备上，不会离开设备。

2. 存储期限：本地数据保存在你的设备上，直至你在「设置 - 隐私与数据」中删除，或卸载本游戏。Firebase Analytics 的事件级数据保留不超过 14 个月，到期后由 Google 自动删除；此后仅保留不含单台设备信息的聚合统计。广告数据由 Google 按其公布的隐私与数据保留政策处理。

3. 超期处理：对于我们控制的个人信息，保存期限届满或处理目的实现后，我们会依法删除或匿名化；法律法规另有规定的除外。

七、我们如何保护你的个人信息

1. 本地存档保存在应用私有存储目录，并采取完整性校验等措施降低数据被篡改的风险。

2. 我们根据个人信息的处理目的与风险采取必要的安全措施；如发生个人信息安全事件，我们会依法采取补救措施，并履行报告与通知义务。

八、你的权利

1. 查阅、复制、更正：对于我们控制且能够依法核实与你关联的个人信息，你可以通过第十一节联系我们行使查阅、复制、更正或补充权利。

2. 删除本地数据：你可以在「设置 - 隐私与数据」中点击「删除我的数据」，删除本机存档、游戏设置与隐私同意记录；也可以卸载本游戏删除本地数据。该操作不会直接删除第三方 SDK 已经依法处理的数据，你可以通过其隐私政策提供的渠道行使权利，或联系我们协助。

3. 撤回同意：你可以在「设置 - 隐私与数据」中关闭同意并保存，我们会停止后续基于同意的采集，不需要重启游戏。撤回不影响撤回前基于同意已经进行的处理活动的效力。

4. 限制个性化广告：你可以关闭「个性化广告」，我们将只请求非个性化广告；在 iOS 上也可以关闭系统跟踪授权。

5. 注销账号：本游戏不设账号，因此不存在账号注销流程。

6. 我们会在法律法规规定的期限内答复你的请求；没有明确期限的，一般在 15 个工作日内答复。

九、未成年人保护

1. 若你是未满 18 周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本游戏。

2. 若你是未满 14 周岁的儿童，应在取得监护人同意后使用本游戏。我们不主动收集你的年龄信息；如监护人发现我们在未获同意的情况下处理了儿童的个人信息，可联系我们依法处理。

3. 本游戏不设账号系统与社交功能，不提供面向陌生人的内容发布、私信与语音聊天。

十、本政策如何更新

1. 本政策更新后，我们会通过游戏内弹窗等合理方式告知。处理目的、处理方式或个人信息种类发生变化，以及法律法规要求重新取得同意的其他情形，我们会重新征得你的同意。

2. 你可以在「设置 - 隐私与数据」中查看最新版本，也可以访问 https://www.starhalobj.com/privacycn.html 查看。
